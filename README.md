# 🛡️ CyberRakshak — AI Cyber Fraud Detection

CyberRakshak is an AI-powered cybersecurity platform designed to detect phishing, scams, malicious URLs, suspicious messages, emails, and online payment fraud.

🌐 **Live Website:** https://techofliger.github.io/CyberRakshak/

🚀 **Features**

* 🤖 AI/NLP-based fraud detection
* 🔗 Malicious URL analysis
* 📱 SMS & WhatsApp scam detection
* 📧 Email phishing detection
* 💳 Payment & QR fraud analysis
* ⚠️ Risk score and threat classification
* 🔴 High Risk / 🟡 Medium Risk / 🟢 Low Risk

🛠️ **Tech Stack**
Python • FastAPI • HTML • CSS • JavaScript • AI/NLP
